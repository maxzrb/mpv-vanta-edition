# 标准与 HQ 色彩模式（2026-10-12）

首次使用默认标准模式，用户从「画面 > 色彩」选择 HQ 高色准后，后续启动记住 HQ；再选标准则记住标准。菜单依次为「标准」「HQ 高色准」「系统 ICC」「查看状态」，HQ 自动处理 SDR／HDR，删除重复目标和恢复入口。系统 ICC 与 HQ 的菜单勾选互斥。缩放／渲染档位独立，原 HQ 缩放、解码线程、硬解策略、字幕及通用范围错误修复保持原样。

原整合包参数仍可在提交 `92085e5` 中找回。`[Target]` 的 `#target-trc=gamma2.2` 和主配置相应行均为注释，原有效目标是 `target-trc=auto`。标准模式按有效设置恢复，不能将历史说明误当成强制 2.2。HDR→SDR 等场景中 auto 可以选择 gamma2.2，SDR 片源则依核心和协商目标处理。

| 色彩项 | 标准（首次默认） | HQ 高色准 |
| --- | --- | --- |
| 主路线 | 原继承自动目标 | 当前自动显示管理 |
| 目标原色／传输函数 | auto／auto | 经典 SDR 为 709／sRGB；ACM／HDR 按模式选择 |
| D3D11 输出 | auto／auto | ACM／HDR 优先 FP16 线性 scRGB；HDR 可回退 PQ／SDR |
| 色域表 I／C／h | 48／32／256 | 96／64／256 |
| HDR 对比度恢复 | 0.30（继承） | 0（准确基线） |
| ICC／显示器峰值 | 不自动应用 HQ 显示偏好 | 保留显示身份／桌面模式／ICC 关联验证 |

标准模式不启用额外的 ACM 浮点输出管理。Windows 及核心的原有输出协商仍按 auto 执行。HQ 浮点工作空间并非对每种显示状态强制 scRGB：经典 SDR 使用 sRGB／可信 ICC，HDR 和 ACM 走各自的软件合同。

主模式保存在 `portable_config/files/color-pipeline-preferences.json`，显示器 ICC／峰值仍使用独立的 `color-target-preferences.json`。未保存主模式偏好时，`script-opts/color-target.conf` 的 `pipeline=standard` 生效。删除主模式偏好文件可恢复配置默认。显式选择系统 ICC 或通过脚本设置 ICC／峰值，会进入 HQ 管线；旧脚本的显示通知不改变标准主模式。原 SDR／HDR／恢复脚本消息保留给高级操作，常规菜单只保留四项。

切换使用原管理器的选项事务和输出配对，保留视频轨、时间、暂停；失败回滚整个事务并保持旧主模式。重复选择同一模式不再撤轨。其他 libplacebo 选项保留；启动时显式指定的表维度作为 HQ 用户覆盖保留。Vulkan 不写 D3D11 输出选项，避免无效选项引发设备重建。手动修改目标后，自动管理仍尊重外部覆盖。
