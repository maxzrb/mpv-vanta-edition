# 菜单磨砂噪点匹配验证 — 2026-10-12

按用户偏好保留标准模式原来的噪点形状、尺寸、密度和强度，将 HQ 的线性输出菜单材质调得更接近标准的细腻观感。修正仅发生在 uosc 的 ASS 面板、噪点、顶部高光与遮罩，未修改视频色彩目标、精度、滤镜、核心或线程。

## 产生差异的原因与实现

原菜单以固定 ASS 颜色和透明度叠加。标准在本机实际输出 BT.1886／RGB10；HQ 使用 BT.709 线性 scRGB／FP16，相同 alpha 会得到不同的亮度起伏。修正前黑背景的 HQ 噪点 RMS 约为标准的四倍。

新增 `uosc/lib/frosted.lua`，按照实际标准目标曲线、黑位和原材质，拟合线性输出下的面板／遮罩颜色及透明度，再校正噪点和高光。采样覆盖从暗到亮的背景，使用有界缓存；纹理仍为原 `uosc_textures` 的 n 字形，尺寸和铺设规则不变。标准模式直接返回原颜色和透明度；非线性目标以及不支持的标准参考曲线也保留原材质，不套用错误的补偿。

输出目标只观察 gamma、原色、最低／最高亮度和主模式等标量。校对实际 `target-trc`／`target-prim` 与已发布标准设置后才记住标准参考，避免切换到 HQ 时先到达的过渡输出污染参考。软件启动直接使用 HQ 而没有标准参考时，使用原经典 BT.1886 基线。

## 实际交换链验证

诊断仅注入本工具启动的隔离播放器。读取 D3D11／Vulkan 的原始交换链，先按实际目标曲线转换为统一 BT.709 线性亮度，再编码为 sRGB 来比较噪点；不直接比较 RGB10 与 FP16 的原始码值。RMS 使用面板内部 200×110 像素、三通道的“开启噪点减关闭噪点”，排除文字、圆角和高光。

| 8 bit 灰背景 | 修正前 HQ／标准 RMS | 修正后 HQ／标准 RMS |
|---|---:|---:|
| 0 | 3.998 | 1.004 |
| 96 | 2.953 | 0.859 |
| 192 | 1.637 | 0.613 |
| 255 | 1.113 | 0.490 |

双后端结果相同。暗场噪点强度与标准相差约 0.4%；亮背景下校正后的噪点更弱。固定 ASS 颜色和共用 alpha 对非线性混合只能拟合，因此仍存在面板色调、亮度及亮场纹理强度的差异，本次不声称全部场景逐像素相同。

- 标准模式的 2 后端×4 背景×2 噪点设置，共 16 张 800×500 完整交换链，匹配开关前后 640 万 RGBA 像素逐字节一致。
- 18 组后端／背景／模式检查中，匹配开关和噪点开关没有改变无菜单视频像素。Vulkan及D3D11黑背景使用去掉标题／动态页脚后的 700×400 视频区域；较早的 D3D11灰背景记录验证了更大的完整交换链一致。
- 本机显式“系统 ICC”选择实际使用 Windows SDR ACM／scRGB，黑背景应用与 HQ 相同的修正；不外推为任意 ICC 曲线的纹理等值。
- 实际“画面 > 色彩”级联菜单在两个后端均验证：标准 → HQ关闭匹配 → HQ开启匹配 → 标准 → HQ。匹配确实改变 HQ 材质，返回标准和返回 HQ 的子菜单内部像素分别与对应首张逐字节一致。
- 1728 组数值边界覆盖深浅主题、四种参考曲线、四种黑位和九层父菜单透明度，颜色及 alpha 均有效；缓存后每对面板／噪点调用约 1.070 微秒，仅为辅助函数微基准，不代表整段播放性能。
- 全脚本双后端六次启动通过首次标准、跨启动记忆、源参数／缩放不变、外部覆盖及重复选择检查。活动 Lua 140 项、Python 118 项语法与已有配置保留检查通过。

中途发现实际切换时将 HQ 过渡输出记为标准参考，已修正并加入 `--live` 回归。Vulkan早期完整交换链比较包含动态页脚，出现不同；随后明确分离视频区域，按实际视频像素复核通过，没有将动态 UI 差异归为视频变化。

## 配置与复查

`portable_config/script-opts/uosc.conf` 默认 `menu_frosted_noise=0.05`、`menu_frosted_match=yes`。将后者设为 `no` 可恢复全部模式原来的材质行为。关闭磨砂时此补偿不工作。

```powershell
.\python.exe tools/test-menu-grain.py --backend d3d11 --background 0 --include-icc --match
.\python.exe tools/test-menu-grain.py --backend vulkan --background 255 --match
.\python.exe tools/test-menu-grain.py --backend d3d11 --live
.\python.exe tools/test-menu-grain.py --backend vulkan --live
.\python.exe tools/test-color-pipeline-modes.py
.\python.exe tools/check-modernization.py --options-baseline-ref 0c9ca8e
```
