## 本地行为

- `Ctrl+f` 或“字幕 → 搜索下载字幕”打开统一入口，默认聚合三源；结果逐步追加，可修改关键词、保留关键词换源。字幕猫只列出实际存在的字幕文件，不触发翻译任务。
- Esc、换词、换片会取消旧任务，迟到回调不能重新打开菜单或加载到下一部影片；下载先暂存，空内容／错误网页／提交失败保留已有文件，选择新主字幕时保留有效副字幕。
- uosc 配置只修改本次动作对应的键，保留最新无关设置、注释、BOM 与原换行。保存失败明确提示本次设置尚未保存，原配置不截断。
- 历史按已存长度及 ignore_same_series 原偏好管理；没有借本轮擅自改历史容量或系列折叠规则。标题裁剪只作用于显示副本。
- 自动连播维持“导航 → 自动连播”单个切换项及默认关闭；用户 remember_size=no 窗口偏好保留。
