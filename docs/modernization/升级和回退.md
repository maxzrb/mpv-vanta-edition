# 组件升级和回退（2026-10-04）

本轮只修改本地配置、组件和安装器源码，未打包、发布或改动《发布流程.md》。现有公开 v1.5.7 安装器不包含本轮旧组件隔离逻辑。

## 日常使用

- 默认关闭 AI、Shader 超分、去色带和轻量时间插值。`Ctrl+0` 恢复本系统原始播放，保留外部脚本／用户拥有的处理项。
- `Ctrl+1/2/3` 保留原 Shader 快捷键，完整库位于「着色器」，VS 位于「视频滤镜」。AI 首次选择会后台准备，完成后再次选择才启用。菜单内可取消；超时默认 120 秒，失败可重试。
- 切集恢复默认增强。原分辨率方案不预降采样；只有标为「性能模式（降至 720p）」的方案显式缩小输入。
- Shader 位于渲染阶段；推荐 AI 固定为降噪 → 超分 → 补帧。同类互斥，高级 Shader 未关闭时拒绝叠加推荐超分。高级手工处理不受推荐管理器自动整理。
- 推荐增强暂时拒绝 HDR／Dolby Vision／广色域输入；普通 gpu-next 播放继续。缺失后端或非 NVIDIA 显卡不会显示 NVIDIA 专用功能为可用。
- SDR 显示器 sRGB 模式采用「色彩目标 → SDR · sRGB」。ICC 入口只在描述文件与当前显示器及模式吻合时使用。HDR 入口需要 Windows HDR 与 HDR 显示器，尚待外部实机验证。

## 本轮回退

1. 退出所有使用本目录的 mpv／Python／TorrServer 进程。
2. 将 `backup/modernization-20261004/` 中的 `mpv.exe`、`mpv.com`、`d3dcompiler_43.dll` 一起复制回根目录；不要只换其中一个。旧版本及校验值见 [升级清单](upgrade-manifest.json)。
3. 如需回退工具，将该备份中的 `yt-dlp.exe`、`TorrServer-windows-amd64.exe` 分别复制回根目录。
4. 画质配置回退需同步恢复本轮修改的 `mpv.conf`、`profiles.conf`、`input.conf`、`stats.lua` 和 `script-opts/stats.conf`，并移走新增 `quality.lua`。初始备份内保留这些文件；其余跟踪文件先检查 `git diff`，不要用全仓库 reset 覆盖用户修改。
5. VS 本轮没有替换。若以后升级失败，恢复 Python、VS、插件、模型及其运行库整套快照，连同匹配的锁定清单与 `.vpy` 配置一起恢复。

徽标回退还需恢复 `startup-format-logos.lua`、`media-format-info.lua` 和 v23 `manifest.json`；新增 DRA 素材可移入备份。用户原有 `startup_format_logos.conf` 没有被本轮覆盖。

本轮开始前已有的状态记录、Logo 配置、窗口尺寸设置和 `.zcode/` 均保留。备份在根目录 `backup/`，不进入 Git 或公开包；换设备前应另外保存需要的本地备份和被忽略的运行时文件。

## 旧安装覆盖与弹幕退役

新版安装器在解压完成并发现 `components.lock.json` 的退役标记后，把以下两项整体移到根目录 `backup/retired-components-时间戳/`，关闭自动加载并保留目录内用户数据：

```text
portable_config/scripts/uosc_danmaku/
portable_config/script-opts/uosc_danmaku.conf
```

普通字幕、其他位置下载的弹幕和历史备份不删除。无新版标记时不迁移；遇到目录链接时拒绝自动搬移。手动解压不能删除旧文件，需手动把这两项移到根目录备份，不能只覆盖新版配置后就认为弹幕已退役。

## 下次升级

1. 保存工作区差异和旧组件，先对官方源做只读审计：`python.exe -X utf8 tools/audit-components.py`。定制脚本按差异合并，不整文件覆盖。
2. 核心取 shinchiro 同一构建的 mpv、随附 DLL、嵌入 FFmpeg 和 libplacebo。核对 GitHub asset SHA-256。更新器使用暂存目录与整套备份，复制失败回滚，并记录新旧校验值；独立 `ffmpeg/ffmpeg.exe` 是工具，不能替代嵌入解码器。
3. VS 必须在隔离目录升级整套依赖。R80 本轮失败，K7sfunc 最新 1.8.1 不能绕过整套回归直接覆盖现有 1.3.1。无需修改系统 PATH；直接启动 `mpv.exe` 必须通过验证。
4. `python.exe -X utf8 tools/snapshot-vs-lock.py` 只生成 `tmp/modernization/components.candidate.json`，不会自动改正式锁。审阅来源、许可和插件／模型差异，完成实际播放回归后才人工替换正式清单。禁止仅重算哈希来掩盖套件被单独修改。
5. 运行实施报告列出的测试，更新版本、来源、校验值和回退位置。本地运行时受 Git 忽略，仅同步配置无法复现完整环境。
6. 后续打包／发布前完整阅读根目录《发布流程.md》，对核心、运行时和包内容变化提交 3.2 Gate 评估。当前插件／模型未明确的许可来源须先补证；本轮不自行豁免、修改流程或创建发布。
