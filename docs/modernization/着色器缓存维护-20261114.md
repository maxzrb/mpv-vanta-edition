# 着色器缓存维护

## 背景与作用范围

2026-11-13 至 14 日核心升级验证时，曾出现同 SHA 核心在根路径 Vulkan 黑帧、干净路径正常；移开 AMD `VkCache` 后，活动核心和实际包的 GPU 数值测试通过。该记录说明这台机器上的驱动缓存曾参与故障，不等同于所有黑屏都由用户 GLSL 或上游核心引起。当前活动核心仍为已验收的 20261110，未改动核心或切换为曾拒绝的 20261111。

清理对象分两层：mpv 的 `portable_config/cache/shaders_cache` 保存编译结果；AMD `%LOCALAPPDATA%/AMD/VkCache` 是当前用户的共享驱动缓存。GLSL 源文件位于 `portable_config/shaders`，不属于清理对象。功能由普通脚本和 Windows 自带 PowerShell 实现，不依赖自编核心。

## 使用方法

播放器菜单「工具 → 缓存维护」：

- **清理着色器缓存（退出后执行）**：仅处理当前配置的 `cache/shaders_cache` 及其子目录。
- **同时重置 AMD Vulkan 缓存（影响其他应用）**：在普通模式基础上，隔离 AMD VkCache 根目录中名称匹配十六进制编号、可选数字后缀的 `.parc` 文件。该缓存不按应用区分，其他应用下次使用也可能重新编译。不存在 AMD 缓存时，只处理 mpv 缓存。
- **查看清理结果**：显示等待、完成、部分完成或失败，以及文件数量和备份路径。

操作先检查路径并安排独立任务，当前播放不变。退出全部标准 mpv／mpvnet 实例（含缩略图子进程）后，任务再次枚举缓存，包含退出阶段最后写入的文件，再执行隔离。显式发起请求的播放器即使使用重命名核心，也会按进程句柄等待。不会结束用户进程；最长等待 24 小时，超时报告失败。下次启动重新编译可能稍慢，正常启动不自动清理。

播放器打不开时，双击 `installer/mpv-清理着色器缓存.cmd`，选择普通或 AMD 模式。其调用的实现为同目录 `clear-shader-cache.ps1`。两个入口放在 installer，配置目录仅保留轻量菜单脚本 `shader-cache.lua`。Windows PowerShell 5.1 默认代码页不同，两个入口均显式以 UTF-8 读取 PowerShell 实现。

## 备份与失败处理

缓存逐文件移动至根目录 `backup/shader-cache/时间-随机编号/`，子目录分别为 `mpv` 和 `amd-vulkan`。`manifest.json` 记录原路径、备份路径、SHA-256、大小及跳过原因，可据此手动恢复；恢复前同样应退出播放器。用户级备份不进入公开包。

没有递归删除目录。移动前校验规范化绝对路径和全部现存祖先；重解析点根目录拒绝，缓存子目录中的联接／符号链接跳过且不跟随。被占用文件记录为部分完成，后续可重新执行。状态文件通过临时文件和原子替换写入 `portable_config/files/shader-cache-cleanup.json`。同一配置的独立任务使用内核互斥量避免重复处理。

自定义 shader cache 只接受当前配置 `cache/shaders_cache` 根或其子目录；外部自定义路径会明确拒绝，避免把任意目录当作缓存清理。普通源着色器、ICC 缓存、历史、进度和个人偏好保留；不处理 NVIDIA／Intel 驱动缓存，也不改变驱动设置或系统 HDR。

## 分发与验证

01 Base 原规则递归复制 installer，自动收录两个入口。04 Config 新增两个文件的显式复制和缺失检查，避免只更新配置包后菜单缺少维护程序；私包合并 01／04，因此同时收录。没有改公开包数量、编号或覆盖顺序，没有改发布流程原件；04 构建脚本有改动，用户已于本次 v1.6.7 发布请求明确“门禁通过”；按原发布流程构建验收，流程原件不修改。

FATE 风格回归：`python -X utf8 tools/test-shader-cache-fate.py`。固定 JSON 样本与 11 行参考输出，覆盖范围保持、AMD 共享缓存过滤、越界、真实目录联接、真实文件锁、只读预览、两实例退出等待、退出阶段新增文件、重复请求、中文／引号／特殊字符路径、旧 0.41 开发核心和当前 0.42 核心、缺少可选读取模块、D3D11／Vulkan 清理后重新生成，以及实际 04 复制片段的依赖覆盖。

测试只操作隔离配置和伪 LOCALAPPDATA 的 AMD 夹具，不执行真实用户驱动缓存清空；未人为注入黑帧，不声称清理能解决所有 Vulkan 故障。运行结果见 [结构化记录](shader-cache-results-20261114.json)。
