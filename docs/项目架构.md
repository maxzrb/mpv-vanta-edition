# 项目架构与目录约定

当前目录同时是 Git 工作区和可直接启动的便携播放器。根目录的 Python／VS／DLL 文件较多，是便携加载需要，不能按文件类型简单移动。日常入口为 `mpv.exe`；只改配置通常进入 `portable_config/`。

## 目录职责

| 位置 | 职责 | 处理约定 |
|---|---|---|
| 根目录 mpv.exe／mpv.com／DLL | shinchiro 核心及匹配运行库 | 整套升级／回退，不混搭 DLL |
| 根目录 Python／VS 文件、Lib／Scripts／vs-*／sdk | 便携 VS 与 AI 套件 | 按 components.lock.json 整套锁定；不为目录美观改变加载路径 |
| portable_config | 唯一活动配置、菜单、脚本、Shader、VS 处理入口 | Git 跟踪；运行时数据例外 |
| mpv/fonts.conf | 当前 shinchiro 随附字体配置 | 是字体运行支持，不是第二套 mpv.conf；保留 |
| lua／socket／mime | Lua 模块与原生依赖 | 保留模块路径 |
| ffmpeg／7z／Faster-Whisper-XXL | 独立工具与可选字幕运行时 | 不与 mpv 内嵌 FFmpeg 混淆 |
| installer／VantaInstaller | 更新／关联脚本与安装器源码 | 安装行为调整与播放器配置分开验证 |
| tools | 维护审计及回归工具 | 不作为普通用户更新入口；见 [工具说明](../tools/README.md) |
| docs/modernization | 组件、菜单、色彩、性能专项报告 | 研究证据与当前实现状态分别写明 |
| docs/codex/STATUS.md | HandShake 当前状态和追加操作日志 | 唯一 AI 项目状态源 |
| version | 中文工作进度与版本历史 | 未发布不修改项目版本 |
| doc | 核心随附上游手册 | 与项目维护文档 docs 分开 |
| build-*.ps1 | 现有包构建入口 | 根目录保留；执行受《发布流程.md》约束 |
| release | 当前发布产物及本地私用包 | 保留完整最新分包及私包；旧版本按清单归档 backup，私包不能公开上传 |
| tmp/modernization | 当前现代化调查、夹具和原始测试输出 | 本地忽略，日志可能含历史／个人路径；完成回归后的 isolated 副本及时归档诊断文本并移入 trash |
| backup | 用户级快照、研究归档和回退清单 | 本地忽略，不进包 |
| portable_config 下各 backup | 曾可用配置／脚本的开发回退 | 按既定约定保留，可 Git 跟踪，随 01／04 包 |
| trash | 已退役程序入口／专有组件等 | 本地忽略，不进包；不视为活动依赖 |

## 活动配置结构

```text
portable_config/
├── mpv.conf、profiles.conf       播放默认值与用户可选配置组
├── input.conf                   快捷键与三种菜单的共同菜单定义
├── scripts/                     自动加载 Lua 脚本
├── script-opts/                 各脚本选项
├── script-modules/              共用 Lua／原生指标模块
├── osc-style/、script-assets/    界面主题与徽标素材
├── shaders/                     完整着色器库
├── vs/、quality/                视频滤镜入口与增强能力清单
├── icc/、fonts/、licenses/       色彩参考、字体及其许可
├── components.lock.json         组件锁与本地差异策略
├── backup/                      开发级旧配置（不自动加载）
└── cache/、files/               Shader／ICC 缓存可按清单清理；watch_later 与 files 用户数据保留
```

菜单保留「着色器／视频滤镜」独立一级分类，画面变换和色彩目标在「画面」；具体当前分布见 input.conf。用户下载字幕、历史及 watch_later 播放进度须保留；可再生成的 Shader／ICC 缓存与完成验收的测试副本可按清单整理。

主要脚本关系：`quality.lua` 管理增强能力、准备与应用；`quality_status.lua` 按需展示处理状态；`color-target.lua` 管理色彩目标及回退；`hdr-mode.lua` 仅在用户开启旧自动 HDR 行为时委托色彩管理器；`stats.lua` 结合 `system_metrics.lua` 管理统计；`startup-format-logos.lua` 结合媒体信息模块显示起播徽标。定制脚本按差异合并上游。

## 2026-10-04 清理归档

归档根为 `backup/project-cleanup-20261004-213930/`，其中 `archive-manifest.json` 记录每个源／目标路径及原因。搬移文件逐个核对 SHA-256；目录整体移动，未递归计算目录内容哈希。没有永久删除文件。

- `tmp/` 原先的 131 个散落文件和 50 个历史子目录归档，保留 `tmp/modernization/`。包括旧下载包、日志、发布测试、临时核心副本；历史报告中的原 tmp 路径现在按清单映射到归档位置。
- 根目录误生成的空 `$gateDir/`、`_nul` 和 `portable_config/backup/dxdiag-tmp.txt` 移至同一归档。诊断文本属于个人数据，不保留在可能随包的开发备份中。
- `installer/configure-opengl-hq.bat` 退役到 `trash/project-cleanup-20261004-213930/installer/`：它会创建旧 mpv/mpv.conf，且使用过时的高画质初始化流程。它不是当前便携配置入口；不提供给用户继续运行。
- `mpv/fonts.conf` 与本轮 shinchiro 原始包逐字节相同，保留。现有四个诊断 BAT、关联脚本、运行库、最新 release 和开发级回退文件保留；旧 BAT 原编码没有被转换。

回退时先关闭有关程序，核对清单与当前同名路径，再按源路径搬回，避免覆盖后来新建的文件。退役 BAT 只用于历史追溯，不推荐恢复使用。后续新增临时产物进入具体任务目录，避免散落 tmp 根目录；研究证据有用途时保留到专项报告收尾。

本轮没有使用 Computer Use，也未启动 VS 播放器 GUI 测试。用户确认所述顺滑表现来自作者内部测试版本，当前下载版性能比较暂停；现有随包 FFmpeg 解码实验不代表该内部版或 GUI 表现。

后续打包／发布须按 [发布流程](../发布流程.md) 核对本轮退役入口、组件变化和包内容，不能据此次本地归档视为发布验收通过。

大分辨率硬解选择由 `hwdec-select.lua` 在预加载钩子中完成，当前文件生效；旧 8k-fix 配置组仅作手动入口。排查依据见 [8K AV1 回退修复](modernization/8K-AV1硬解回退修复.md)。
