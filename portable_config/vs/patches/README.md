# K7 色彩维护补丁

本目录保存已在本机 K7sfunc 1.8.1 上验证的修改配方与上游 GPL 许可。修改源矩阵、范围及通用整数 YUV 格式保留；不改变模型 IO 精度，也不强制 SVP 等后端处理 16bit。

已安装的本机运行库已经应用补丁。播放器直接初始化真实滤镜，不读取配方，不运行应用工具，也不要求用户再次开启。

维护者更换运行库后，可先运行 `python.exe -X utf8 tools/apply-k7-color-fixes.py` 查看匹配状态，再手动使用 `--apply` 合并。工具只接受配方记录的源文件或已应用版本，保留 UTF-8 编码并建立根目录 backup；遇到其他修改需维护者合并，不能直接覆盖。它会刷新组件清单中的相关摘要并保留其他补丁记录。

上游升级后应重新审阅实现和回归，不将 1.8.1 配方强套到其他版本。配方中的版本检查属于维护操作，不接入起播、菜单或滤镜选择。
