- 背景：资产列表链路为「用户浏览器 → /api/latest → GitHub API」，GitHub API 限流/超时/被墙时页面直接报“无法连接”，即使下载通道本身正常也看不到列表、点不了下载。

- KV 自动快照全自动维护，**发布后无需手动更新**：每次 GitHub API 拉取成功即回写 KV（键 `snapshot:latest`，TTL 7 天）；另加 `scheduled` 事件处理器 + Cron Trigger 定时刷新 KV（需在 Cloudflare 面板配置，如每 6 小时）。
- 内置硬编码快照 `FALLBACK_RELEASE`（当前 v1.5.1）降级为最后一道防线（KV 未绑定/为空时兜底），无需频繁更新；`tools/update-worker-snapshot.ps1` 保留为可选工具（首次部署无 KV 或想双保险时强制同步硬编码快照）。
- 前端按来源显示徽标：实时（绿）/ 缓存（蓝）/ 自动快照（靛）/ 离线快照（橙，附“可能滞后”提示）；`/api/latest` 整体失败时浏览器直连 GitHub API 作为二级兜底。
- 验证：`node --check` 外层 JS 与提取的前端 JS 均通过；Node 仿真 Worker 运行时六条路径全过（live→写 KV / cache 命中 / API 失败→KV 快照 / scheduled→写 KV / API 失败→scheduled 的 KV / API 失败+KV 空→内置快照）；脚本 ps1 语法解析通过。
- Cloudflare 侧需一次性配置：创建 KV Namespace 并绑定到 Worker（变量名 `SNAPSHOT_KV`），配置 Cron Trigger（如 `0 */6 * * *`），再部署新代码。
